## Say Hello to xv6

### How to compile and run xv6? 

See instructions here: https://github.com/qyliu-hkust/ostep-projects/blob/master/INSTALL-xv6.md

### Project Target

- Compile and run xv6 in qemu
- Hack into `/user/printf.c` and implement function `void puts(const char *str)` (similar to the one in standard C library)
- Use the implemented `puts` to implement a binary utility `hi` executable on xv6 to print `Hi, xv6!`


### For Submission

- Source code (`printf.c` and `hi.c`)
- Project report
- Bonus question: What's the difference between the implemented `puts` and the one in standard C library?
